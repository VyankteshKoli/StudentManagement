# Student Management System

A simple **Student Management System** built using **Java and Spring Boot**.  
This project provides REST APIs to perform CRUD operations on student data and stores records in a **MySQL database**.

---

## 🚀 Tech Stack
- Java
- Spring Boot
- Spring Data JPA
- MySQL
- Maven
- REST API

---

## ✨ Features
- Add new student
- Get all students
- Get student by ID
- Delete student by ID
